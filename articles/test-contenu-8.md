# Google — récapitulatif IA (juin) : implications pratiques pour Marc

## Points clés
- Gemma 4 12B : modèle ouvert conçu pour fonctionner localement sur un portable avec 16 Go de RAM ; intègre vision et traitement vocal natif.
- Gemini 3.5 Flash : capacité « computer use » pour construire agents capables de voir, raisonner et agir à travers desktop / mobile / navigateur ; amélioration pour tâches d’automatisation longue portée.
- Nano Banana 2 Lite : nouveau modèle image annoncé comme disponible ; Gemini Omni Flash : multimodal vidéo en aperçu public via API.
- Gemini 3.5 Live Translate : modèle audio détectant >70 langues, déployé via Gemini Live API, Google AI Studio et l’app Google Translate (déploiement annoncé).
- NotebookLM : enrichi (raisonnement avancé, exécution de code dans un cloud sécurisé, génération de graphiques/tableaux/diapositives) — disponible globalement pour abonnés Google AI Ultra et certains comptes Workspace.
- Android 17 / Pixel Drop : nouvelles fonctions (fenêtres flottantes, Screen Reactions, outils AI pour création vidéo/musique, traduction vocale en temps réel) ; Android 17 déploiement initial sur Pixel puis autres appareils pendant 2026.
